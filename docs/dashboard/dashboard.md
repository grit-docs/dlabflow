# 대시보드
## 개요
* 대시보드에서는 데이터 저장소, 데이터셋, 프로젝트, 운영 등 주요 지표를 한눈에 파악할 수 있습니다. 값 영역의 주요 수치는 우측 상단에 표시되는 최근 업데이트 시간 기준의 누적 값이며, 우측에는 오늘 하루 동안의 증감이 표시됩니다.
  <div style={{ textAlign: 'center' }}>
    <img src={DashboardImg} alt="대시보드 화면" style={{ width: '100%' }} />
  </div>

<br />


* 저장소 현황에서는 전체 저장소(하위 저장소 제외)와 크롭 관리를 통해 생성된 하위(크롭) 저장소 수를 나타내며, 업로드된 이미지와 정형 데이터 파일의 원본 수, 크롭 기능 활성화에 따라 자동으로 생성된 파일 수도 확인할 수 있습니다.
  <div style={{ textAlign: 'center' }}>
  </div>

<br />

* 데이터셋 현황에서는 이미지 데이터셋과 정형 데이터셋의 개수를 표시하며, 각 파일 수는 데이터셋-저장소 선택에서 활성화된 파일 수를 의미합니다.
  <div style={{ textAlign: 'center' }}>
  </div>

<br />

* 프로젝트 현황에서는 프로젝트 수, 버전 수, 학습 완료된 버전과 학습 중인 버전 수를 통해 진행 상황과 상태를 알 수 있습니다.
  <div style={{ textAlign: 'center' }}>
  </div>

<br />

* 운영 현황에서는 등록된 사용자 수, 수집 장치 수와 함께 최근 일주일간 프로젝트에서 학습을 요청한 건수 와 학습에 실패한 건수를 확인할 수 있습니다.
  <div style={{ textAlign: 'center' }}>
  </div>

<br />
