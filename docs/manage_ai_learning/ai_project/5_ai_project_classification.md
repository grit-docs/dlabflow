# AI 프로젝트 (정형데이터 분류)

표 형태의 정형 데이터를 분석하고 분류하는 머신러닝 모델을 학습

# 버전 생성
버전 생성은 학습을 위한 준비를 하는 과정으로, 시스템 내부적으로 학습에 사용될 파일을 학습 공간으로 옮기는 동작이 수행됩니다.

과정에 있어서 사용자가 **학습 파일 정보**, **학습/시험 데이터 분할**, **데이터 전처리**, **학습 데이터 증강** 을 설정 하였다면 해당 설정이 함께 반영됩니다.

## 학습 파일 정보

|        구분         | 내용                                                                               |
|:-------------------:|------------------------------------------------------------------------------------|
|     **파일 수**     | 선택한 데이터셋에 포함된 파일수를 나타냅니다.(실제 학습 가능한 파일수가 아닙니다.) |
|  **행(Row) 개수**   | 선택한 데이터셋에 포함된 라벨링 수를 나타냅니다.                                   |
| **열(Column) 개수** | 선택한 데이터셋에 포함된 클래스 수를 나타냅니다.                                   |

학습 파일 정보는 프로젝트에서 활용 가능한 데이터셋 의 대략적인 수치를 확인할 수 있게 합니다.
실제 데이터셋의 정확한 성격과 특징, 수치적 허용 범위는 표현과 다를 수 있습니다.

## 데이터 전처리
전처리를 통해 데이터 품질을 높이고 모델의 학습 성능과 안정성을 개선할 수 있습니다.

이상치 처리 : 데이터셋에서 비정상적으로 크거나 작은 값(이상치)을 탐지하고 제거하는 과정입니다. 

방법 : 대상 컬럼(속성)을 선택하고 우측의 처리 방법을 선택한다.

현재 처리방법으로는 **사분위수 삭제**를 제공한다.
