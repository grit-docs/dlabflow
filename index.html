CORE FEATURES

데이터 준비부터 모델 운영까지​

D-Lab Flow의 주요 기능을 업무 흐름에 따라 확인할 수 있습니다.

데이터 저장소와 업로드

이미지와 정형데이터 저장소를 생성하고, 파일 또는 폴더를 직접 업로드할 수 있습니다. 사용자 업로드와 장비 업로드를 구분해 데이터를 관리합니다.

수집 장치 연동

카메라, 센서와 엣지 장치의 연결 정보를 생성하고, 현장 데이터를 지정된 장비 업로드 저장소로 자동 수집할 수 있습니다.

데이터셋과 협업 라벨링

저장소의 데이터를 학습용 데이터셋으로 구성하고, 바운딩 박스와 폴리곤 라벨링을 수행합니다. 팀원별 작업 분배와 클래스 통계도 확인할 수 있습니다.

목적별 AI 프로젝트

객체 탐지, 인스턴스 분할과 정형데이터 분류 프로젝트를 생성하고, 프로젝트 목적에 맞는 데이터셋과 학습 조건을 설정합니다.

학습 버전과 성능 비교

하나의 프로젝트에서 여러 학습 버전을 생성하고, 데이터 전처리·증강·하이퍼파라미터 설정에 따른 결과를 비교할 수 있습니다.

모델 평가와 배포

평균정밀도, 정밀도와 재현율을 비교해 모델을 선택하고, PyTorch·ONNX·OpenVINO 형식으로 다운로드할 수 있습니다.
